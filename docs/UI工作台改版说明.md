# 单窗口工作台改版

日期：2026-10-21。

本次采用一套统一界面，保持原有“添加输入 → 选择输出 → 开始处理”的工作流及 BAT/VBS 入口。

## 布局

- 顶部：工具名称、处理规则入口、输出模式与保存位置、打开输出。
- 阶段条：递归解压、文件处理、作品命名，分别展示等待、进行中、完成或异常状态。
- 左侧：拖入文件和文件夹、双行输入列表、完整选中路径、移除与清空。
- 右侧：可换行的实时日志，阶段标题、失败及全部完成使用不同文字颜色。
- 底部：从实际配置读取的处理规则摘要、最终结果、耗时、开始与停止、当前阶段进度。

默认客户区为 1040 × 690，最小窗口为 900 × 650；使用布局容器和 DPI 缩放，左右区域可调整宽度。

## 状态含义

解压阶段只统计已结束的分组，失败同样计入结束数量。音频处理与命名没有可靠的整体总量，采用动态进度提示。只有进程退出代码 0 显示“全部完成”。异常、部分失败、命名待补全和停止状态保留到下一次运行，不再被统一重置为“就绪”。

本次未改动解压、音频删除、MP4 删除或命名的执行规则。规则窗口为只读说明。停止仍执行原来的进程树终止，不声称支持暂停或在当前文件完成后停止。

如需回退界面，关闭新版窗口，将备份中的 `extract-gui.ps1` 复制回项目根目录即可恢复原入口界面；新增模块不再被加载。无需回退配置或处理脚本。

## 验证边界

已使用界面真实按钮与定时器，连接临时模拟进程验证：Unicode 与空格路径、指定输出和原地址参数、运行中禁止追加输入、三阶段切换、完成与部分失败、命名待补全、停止以及最小窗口和 125% 布局缩放。检查并查看原生 WinForms 渲染图。

这些验证覆盖界面调度和状态显示。本次没有对用户真实压缩包执行解压、转换或删除；实际处理引擎保持原文件。
